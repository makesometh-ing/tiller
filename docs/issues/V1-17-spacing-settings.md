# V1-17: Spacing settings

Work file: [F30](../work/F30-spacing-settings.md)

## What to build

- Make 3 mockups in the light and the dark appearance for approval.
- Settings for the workspace margin, the container margin and the carousel spacing. The defaults are 10, 10 and 30 points.
- A change is applied at once to each workspace.

## Acceptance criteria

- [ ] A change of each value moves the test windows to the new frames at once.
- [ ] The values are kept after a relaunch.

## Proof

Screenshots of the mockups, of the settings page, and of the test windows before and after each change.
