# V1-18: Show Tiller in the menu bar, the Dock or both

Work file: [F32](../work/F32-menu-bar-and-dock.md)

## What to build

- A "Show Tiller in" setting on the General page, as in variant 2 in [general-page.html](../mockups/general-page.html): a segmented control with "Menu bar", "Dock" and "Both". The default is "Menu bar".
- A change is applied at once, without a relaunch.
- With "Dock only", a click on the Tiller icon in the Dock opens the settings.
- The Dock menu of Tiller contains "Enable Tiller" and "Settings…".

## Acceptance criteria

- [ ] Each value shows the Tiller icon only in the selected places.
- [ ] With "Dock only", a click on the Dock icon opens the settings.
- [ ] The value is kept after a relaunch.
- [ ] The General page matches variant 2 in the light and the dark appearance.
